📚 Fundamentals of Data Structures (FDS) — Architectural Reference

1. Queue (Linked Queue)

  • Structure: Dynamic nodes with front and rear pointers.
  • Discipline: First-In, First-Out (FIFO).
  • Time Complexity: Enqueue: \(\mathcal{O}(1)\), Dequeue: \(\mathcal{O}(1)\).
  • Rescue Role: Ensures fair, chronological dispatch of emergency relief parties.

2. Singly Linked List

  • Structure: Heap-allocated ResourceNode with next pointer.
  • Discipline: Linear sequential traversal.
  • Time Complexity: Insertion at Head: \(\mathcal{O}(1)\), Search / Allocate: \(\mathcal{O}(N)\).
  • Rescue Role: Dynamic addition of disaster inventory without predefined size limits.

3. Graph & BFS / DFS

  • Structure: Static \(20 \times 20\) Adjacency Matrix adj[u][v].
  • BFS (Breadth-First): Uses a FIFO Queue to explore node levels radially.
  • DFS (Depth-First): Uses Recursion (Call Stack) to explore branches deeply.
  • Time Complexity: \(\mathcal{O}(V^2)\) for Adjacency Matrix traversal.
  • Rescue Role: Reachability verification and evacuation path discovery.

4. Stack (Array-based)

  • Structure: Fixed-capacity array of size 100 with top index.
  • Discipline: Last-In, First-Out (LIFO).
  • Time Complexity: Push: \(\mathcal{O}(1)\), Pop: \(\mathcal{O}(1)\).
  • Rescue Role: Chronological audit log; foundational structure for undo operations.
